# Каталог firmware

Готовые образы оригинальной или модифицированной прошивки намеренно не хранятся в репозитории.

Чтобы получить русскую версию:

1. самостоятельно получите официальный `LiteVNA64 v1.4.08.bin`;
2. проверьте его SHA-256;
3. запустите `patcher/patch_litevna_ru.py`.

Такой подход позволяет распространять русскую локализацию, не включая в репозиторий полный исходный образ прошивки LiteVNA.
