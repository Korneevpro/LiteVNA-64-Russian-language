# Патчер

`patch_litevna_ru.py` создаёт локализованный BIN из чистой официальной прошивки LiteVNA64 v1.4.08.

## Требования

- Python 3.9+;
- внешние библиотеки не нужны.

## Использование

```bash
python patcher/patch_litevna_ru.py "LiteVNA64 v1.4.08.bin"
```

С выбором имени результата:

```bash
python patcher/patch_litevna_ru.py "LiteVNA64 v1.4.08.bin" -o litevna_ru.bin
```

Патчер жёстко проверяет SHA-256 исходного образа и не применяет смещения к неизвестной версии прошивки.


## Контроль результата

Для поддерживаемого исходного BIN:

- SHA-256 исходного файла: `22f91d4769b81b058343ad94055cbd94a2cffbc7e0378619a94d6abfc515d501`;
- размер результата: **94506 байт**;
- SHA-256 результата: `67fa2538b87730aa74aef6517d99aca834eee58ea4e4d26d01952f74c88f7516`.

Патчер также восстанавливает полный служебный диапазон таблицы шрифта `0x0B…0x15`. Это исправляет штатный символ сопротивления **Ω** в строках измерений, не затрагивая кириллические глифы.
