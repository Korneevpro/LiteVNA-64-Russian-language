# LiteVNA Russian — русская локализация LiteVNA64 v1.4.08

Независимый проект русской локализации интерфейса **LiteVNA64** для прошивки **v1.4.08**.

Русификация подготовлена и протестирована для **Zeenko ZN-406 / LiteVNA64, HW 64-0.3.3**. В локализованной прошивке сохранены измерительные функции оригинальной версии, добавлен русский шрифт, расширена панель меню и переработаны подписи так, чтобы они были понятны не только опытному пользователю NanoVNA/LiteVNA.

**Автор русской локализации: R3DQB.**  
В экране «О приборе» локализованная версия содержит строку `Translation Russian R3DQB`.

## Основные изменения

- русский интерфейс основных меню и большинства вложенных пунктов;
- отдельный кириллический шрифт без порчи штатных ASCII-символов;
- расширенная панель меню — **112 px** вместо штатных **91 px**;
- корректное ограничение области графика при открытом расширенном меню;
- осмысленный перевод вместо буквальной кальки;
- сохранены общепринятые обозначения **S11, S21, TDR, dB, КСВ, LC, SD, USB**;
- русифицированы меню графиков, частот, калибровки, измерений, SD-карты, TDR и настроек;
- в разделе «О приборе» добавлена отметка о русской локализации.

## Почему в репозитории нет оригинальной прошивки

Репозиторий **не распространяет оригинальный BIN LiteVNA** и не заявляет права на исходную прошивку. Пользователь должен получить оригинальную `LiteVNA64 v1.4.08.bin` из официального источника и самостоятельно применить патч.

Это сделано намеренно: права на оригинальную прошивку принадлежат её авторам и правообладателям. Проект распространяет только собственный код, документацию и механизм преобразования официального образа.

Подробнее: [Уведомление о правах](NOTICE.md).

## Поддерживаемая исходная прошивка

| Параметр | Значение |
|---|---|
| Модель | LiteVNA64 |
| Версия | v1.4.08 |
| Размер исходного BIN | 88128 байт |
| SHA-256 исходного BIN | `22f91d4769b81b058343ad94055cbd94a2cffbc7e0378619a94d6abfc515d501` |
| Размер локализованного BIN | 94506 байт |
| SHA-256 локализованного BIN | `67fa2538b87730aa74aef6517d99aca834eee58ea4e4d26d01952f74c88f7516` |
| Адрес прошивки | `0x08004000` |

Патчер **откажется работать**, если контрольная сумма исходного файла отличается.

## Быстрый старт

1. Получите оригинальный файл `LiteVNA64 v1.4.08.bin`.
2. Установите Python 3.9 или новее.
3. Выполните:

```bash
python patcher/patch_litevna_ru.py "LiteVNA64 v1.4.08.bin"
```

4. Будет создан файл `LiteVNA64_v1.4.08_RU_R3DQB.bin`.
5. Прошейте его с адреса **`0x08004000`**.

Подробная инструкция: [docs/ПРОШИВКА.md](docs/ПРОШИВКА.md).

Для Windows отдельно описана установка драйвера **AT32 Bootloader DFU**: [drivers/README.md](drivers/README.md).

Для записи используется браузерный **WebUSB DFU Flasher** DiSlord:
https://dislord.github.io/WebUSB-DFU-Flasher/webusb_dfu.html

## Важное предупреждение

Прошивка микроконтроллера всегда связана с риском. Перед экспериментами рекомендуется считать полный дамп внутренней Flash и сохранить оригинальный BIN. Для AT32 Bootloader DFU не изменяйте Option Bytes без необходимости.
