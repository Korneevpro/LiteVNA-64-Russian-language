# История изменений

## RU 1.0 — 2026-10-02

Первый оформленный релиз русской локализации на базе LiteVNA64 v1.4.08.

### Интерфейс

- добавлен отдельный русский набор глифов;
- переведено главное меню;
- переведены основные подменю графиков, меток, частот, калибровки, измерений, SD-карты и настроек;
- переведено меню TDR;
- международные обозначения S11, S21, TDR, dB, КСВ, LC, SD и USB сохранены;
- большинство сокращений заменено полными русскими формулировками;
- подписи переработаны с учётом фактического назначения функций.

### Геометрия

- ширина панели меню увеличена с 91 до 112 пикселей;
- рабочая область графика корректно уменьшается при открытии расширенного меню;
- исправлено наложение графика и результатов измерения на панель меню.

### Шрифт

- добавлены кириллические заглавные буквы;
- сохранена штатная ASCII-таблица;
- скорректированы отдельные глифы и межбуквенные интервалы.

### Информация о версии

В экран «О приборе» добавлена строка `Translation Russian R3DQB`.
