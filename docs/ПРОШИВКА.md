# Прошивка LiteVNA64

## Перед началом

Убедитесь, что у вас:

- LiteVNA64 совместимой аппаратной ревизии;
- оригинальный `LiteVNA64 v1.4.08.bin` с правильной SHA-256;
- сохранён исходный BIN;
- желательно снят полный дамп внутренней Flash.

## Создание русской прошивки

```bash
python patcher/patch_litevna_ru.py "LiteVNA64 v1.4.08.bin"
```

Ожидаемый исходный SHA-256:

```text
22f91d4769b81b058343ad94055cbd94a2cffbc7e0378619a94d6abfc515d501
```

Ожидаемый SHA-256 результата:

```text
368f443dc288b7be337d638db00b2858bd0f1530154de81449391ed3b7fb1bc7
```

## Вход в AT32 Bootloader DFU

На протестированном LiteVNA64 загрузчик определяется как:

```text
Manufacturer: Artery Technology
Device: AT32 Bootloader DFU
VID:PID: 0x2E3C:0xDF11
Internal Flash: 0x08000000..0x080FFFFF
```

## Резервная копия

Перед записью рекомендуется считать всю Internal Flash:

```text
Start: 0x08000000
End:   0x080FFFFF
Размер: 1 MiB
```

Option Bytes без необходимости не изменяйте.

## Запись локализованной прошивки

```text
Flash start address: 0x08004000
Erase before flashing: ON
Verify after flashing: ON
```

После записи дождитесь успешной проверки и только затем перезагрузите прибор.

## Восстановление

Если приложение не запускается, но AT32 Bootloader DFU доступен, снова войдите в DFU и запишите оригинальный BIN приложения с адреса `0x08004000`.

Полный 1 MiB дамп следует использовать только как аварийный резерв и с пониманием структуры Flash.
