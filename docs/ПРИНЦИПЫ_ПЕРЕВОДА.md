# Принципы перевода интерфейса

Русификация не является пословным переводом английского меню. Главный принцип — пользователь должен понимать назначение пункта даже при первом знакомстве с прибором.

## Примеры

| Оригинал | Русский интерфейс | Причина |
|---|---|---|
| DISPLAY | ГРАФИКИ | раздел управляет в первую очередь представлением измерений |
| MARKER | МЕТКИ | естественный русский термин |
| STIMULUS | ЧАСТОТЫ | здесь задаётся диапазон и параметры частотного сканирования |
| RECALL | ЗАГРУЗИТЬ | описывает действие, а не внутренний термин |
| TRACE | ГРАФИК | понятнее новичку, чем «трейс» |
| SWR | КСВ | привычный русскоязычный радиотехнический термин |

## Что не переводится полностью

Сохраняются международные обозначения, полезные при работе с документацией и учебными материалами: S11, S21, TDR, dB, LC, SD, USB и обозначения калибровочных эталонов OPEN / SHORT / LOAD / THRU.

## Ограничения

Русские строки должны помещаться в экран 480×320. Панель меню расширена до 112 пикселей, поэтому большинство слов написано полностью и перенесены на две строки без агрессивных сокращений.
