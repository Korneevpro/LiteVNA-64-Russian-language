# Технические заметки о локализации

## Базовая прошивка

Проект рассчитан на чистый образ LiteVNA64 v1.4.08 с SHA-256:

`22f91d4769b81b058343ad94055cbd94a2cffbc7e0378619a94d6abfc515d501`

Приложение загружается по адресу `0x08004000`.

## Почему используется патчер

Работа велась с готовым бинарным образом: анализ строк, таблиц шрифтов, указателей и отдельных участков машинного кода.

Патчер не хранит полный исходный BIN. Результат формируется из диапазонов официального исходного файла пользователя и новых данных, созданных проектом.

## Шрифт

Штатная таблица ASCII не заменяется русскими буквами. Для локализации используется расширенная таблица с кириллическими заглавными символами. Это сохраняет штатные цифры, латиницу, знаки пунктуации и единицы измерения.

## Панель меню

- исходная ширина: 91 px;
- русская версия: 112 px.

При входе в меню рабочая область графика уменьшается синхронно с новой шириной, чтобы измерения не перерисовывали меню.

## Проверка результата

Патчер проверяет SHA-256 как входного, так и выходного файла.
